# JES FIT Suplementos

Catálogo web adaptable para GitHub Pages. Incluye carruseles horizontales para Creatinas, Proteínas, Pre-entrenos, Vitaminas, Aminoácidos y Accesorios; búsqueda, filtros, formulario validado, WhatsApp, modo claro/oscuro, indicador de conexión y soporte PWA/offline.

## Publicar en GitHub Pages
1. Descomprime el ZIP.
2. Sube **todos** los archivos y carpetas a la raíz del repositorio (no solo `index.html`).
3. En GitHub entra a Settings → Pages.
4. En Build and deployment selecciona Deploy from a branch, rama `main` y carpeta `/ (root)`.
5. Guarda y espera la URL de GitHub Pages.

El catálogo incluye datos y precios referenciales de demostración; confirmar precios y stock con la tienda. Las ilustraciones SVG locales aseguran que siempre se vean imágenes aunque no carguen servicios externos.
